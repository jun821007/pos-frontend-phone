# POS 手機版分頁空白問題 - 處理紀錄

**最後更新：** 2025/03/12  
**專案：** pos-frontend-phone  
**部署：** pos-jun.netlify.app  

---

## 一、問題描述

- **現象：** 手機版（含電腦模擬手機寬度）點「未結」「歷史」「今日」「進貨」「設定」等分頁，內容區為空白
- **正常分頁：** 「收銀」「同行對帳」可正常顯示
- **環境：** 手機、電腦皆會發生，與裝置、瀏覽器無明顯關係
- **發生時間：** 約在新增「同行對帳」功能後開始出現

---

## 二、已嘗試的修正（均無效）

| 項目 | 作法 | 結果 |
|------|------|------|
| 移除 mobile @media | 刪除覆寫 body/main/view-section 的 `@media (max-width:767px)` | 無效 |
| 移除 min-h-0 | 從各 view-section 移除 `min-h-0`，對齊 index-from-751 | 無效 |
| html 高度 | 移除 `height: 100dvh`，只保留 `min-height` | 無效 |
| position: fixed | view-section 改用 `position: fixed` 避開 flex | 無效 |
| 清除 Netlify 快取 | Deploy without cache | 無效 |
| 隱藏同行對帳 | 用 CSS 隱藏 #view-peer、相關 nav | 無效 |

---

## 三、版面結構（index.html）

```
body (h-screen flex flex-col)
├── aside (桌面側欄, md:flex)
├── main (flex-1 flex flex-col relative)
│   ├── header (h-14)
│   ├── view-pos      ← 收銀，正常
│   ├── view-report   ← 今日，空白
│   ├── view-peer     ← 同行對帳，正常
│   ├── view-pending  ← 未結，空白
│   ├── view-history  ← 歷史，空白
│   ├── view-restock  ← 進貨，空白
│   ├── view-setting  ← 設定，空白
│   └── view-category-sort
└── nav (手機底欄, fixed bottom)
```

**view-section 共同結構：**
- `class="view-section flex-1 flex flex-col overflow-hidden p-4"`（無 min-h-0）
- 以 `hidden` class 切換顯示／隱藏
- `switchView()` 會對所有 view-section 加 `hidden`，只移除目前 view 的 `hidden`

---

## 四、與正常版（index-from-751）的差異

- index-from-751 為 UTF-16 編碼，無法直接使用
- 版面結構已對齊 751（無 min-h-0、無問題 @media）
- 目前 index.html 已移除先前嘗試的修正 CSS

---

## 五、關鍵程式碼位置

| 功能 | 位置（約略行數） |
|------|------------------|

| Hash 直連 | `fetchData()` 約 681 行，支援 `#setting`、`#report` 等 |
| 同行對帳 | 目前已用 CSS 隱藏 `#view-peer`、`#d-nav-peer`、`#m-nav-peer` |

## 六、已知資訊

- `test-setting.html` 單獨開啟可正常顯示，表示問題與主程式的 flex 版面有關
- 收銀、同行對帳能顯示，表示切換邏輯與部分 view 可正常運作
- 隱藏同行對帳後問題仍在，顯示與 view-peer 的 DOM 結構無直接關聯

---

## 七、待釐清與下一步

1. **需要實際除錯：** 以 Chrome DevTools 遠端偵錯或手機模擬器，檢查：
   - 空白分頁的 `view-section` 實際 `display`、`height`、`overflow`
   - 是否有 JS 錯誤
   - `switchView()` 後該 view 的 `hidden` 是否正確被移除
2. **其他方向：** 可能與 Tailwind、flex 計算、Safari 特定行為有關，需進一步檢視
3. **目前 CSS：** 含暫時隱藏同行對帳的規則（約第 65–66 行）
