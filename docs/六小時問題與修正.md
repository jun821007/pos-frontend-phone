## 二、Railway 後端 crash

### 問題
- 錯誤: SyntaxError: Invalid or unexpected token
- 位置: server.js 第 70 行
- 原因: console.log 內中文/emoji 因 PowerShell 寫入產生 UTF-8 編碼損壞

### 修正
- 將損壞的 console.log 改為英文 [ENV CHECK]、exists、type、length 等
- 移除重複且損壞的 log
- (蝛?) 改為 (empty)
- 檔案: pos-backend/src/server.js

### 影響
- 後端整個 crash 無法啟動，導致無法登入（非登入邏輯問題）
