## 四、技術注意事項

1. **編碼**：PowerShell 的 `Set-Content -Encoding UTF8` 易造成中文亂碼，建議用 Node 讀寫或手動編輯。
2. **StrReplace 工具**：有時會失敗，可用 Node 腳本或 PowerShell 做字串替換。
3. **行尾**：檔案可能為 CRLF，替換時注意。
4. **登入試算表**：帳號工作表欄位 A=帳號、B=密碼、C=名稱、D=role（Y/admin→admin，其他→cashier）。
