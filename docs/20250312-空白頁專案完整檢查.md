# 手機版空白頁 — 專案完整檢查

> 建立日期：2025-03-12

---

## 一、部署說明（重要）

### 前端 vs 後端

| 項目 | 部署 | 改 index.html 後 |
|------|------|------------------|
| pos（前端） | Netlify | 必須重新部署 Netlify 才會生效 |
| pos-backend | Railway | 後端才需 deploy |

### 重點：只改本地 index.html 沒用

改完 pos/index.html 後，一定要重新 deploy 到 Netlify，手機開 Netlify 網址才會看到更新。

方式：Netlify 專案 → Production deploys → 拖放更新後的 pos 資料夾，或 push Git。

---

## 二、各分頁邏輯

| 分頁 | 觸發 | 預期 | 空白可能原因 |
|------|------|------|--------------|
| 未結 | openPending → loadPending | 標題+列表或「無未結帳款」 | API 失敗、401 |
| 歷史 | openHistory → setQuickDate | 日期欄+按鈕，列表要按搜尋才載入 | 正常初始為空 |
| 進貨 | switchView(restock) → setRestockMode | 按鈕+搜尋欄+網格 | DB.inv 空或 fetchData 失敗 |
| 設定 | switchView(setting) | 靜態 HTML，一定有「系統設定」 | 若也空白→版面問題 |

設定是純靜態，若連設定都空白，多半是 CSS/版面。

---

## 三、版面現況（已套用）

- body: h-[100dvh]
- main: min-h-0, pb-16
- 手機 main: height: calc(100dvh - 4rem)
- view-section: min-h-0

若仍空白：檢查 100dvh 相容、z-index、view 的 height 是否為 0。

---

## 四、排查順序

1. 確認已重新 deploy Netlify
2. 確認手機開的是 Netlify 網址
3. 完全無字 vs 有標題但列表空 → 區分版面問題或 API 問題
4. 用 Chrome 遠端除錯檢查 view 高度、Console、Network
