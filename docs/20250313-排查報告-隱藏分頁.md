# 空白頁排查報告 — 隱藏分頁相關

> 2025-03-13

---

## 一、initSystem「隱藏」邏輯

```javascript
if(User && !User.isAdmin) {
  ['d-nav-report','d-nav-history','d-nav-peer','d-nav-pending',
   'm-nav-report','m-nav-history','m-nav-peer','m-nav-pending'].forEach(id => { 
    const el = document.getElementById(id); 
    if(el) el.style.display = 'none';
  }); 
}
```

**只做一件事**：對非 admin 把這 8 個 nav 按鈕設成 `display: none`。  
**不會改動**：view-report、view-pending 等 view 的 DOM，也不動任何 view 的 class。

---

## 二、各分頁開啟流程

| 分頁 | 觸發 | 流程 |
|------|------|------|
| 今日 | openReport() | switchView('report') → renderReport() |
| 未結 | openPending() | switchView('pending') → loadPending() → renderPendingList() |
| 歷史 | openHistory() | switchView('history') → setQuickDate() → doHistorySearch() → renderHistoryList() |
| 同行 | openPeer() | switchView('peer') → showPeerListPanel() → loadPeerList() |
| 進貨 | switchView('restock') | setRestockMode() |
| 設定 | switchView('setting') | 無額外邏輯 |

---

## 三、可能成因（依「隱藏後才出問題」推測）

1. **initSystem 的 display:none 間接影響**  
   機率低，但可驗證：暫時註解掉上述 forEach，看空白是否消失。

2. **index-from-751 與目前版本結構差異**  
   - 751：body 用 `h-screen`，main 無 `min-h-0`、無 `pb-16`  
   - 目前：body 用 `min-h-[100dvh] h-[100dvh]`，main 有 `min-h-0`、`pb-16`  
   若這些是後來加上去的，可試著還原為 751 的 body/main 結構。

3. **JS 未執行或出錯**  
   - 可加上 `console.log`，確認 openReport、renderReport、loadPending 等是否被呼叫。  
   - 設定頁為純 HTML，若也空白，表示問題多半在版面，而非 JS。

---

## 四、建議驗證步驟

### A. 暫時關閉 nav 隱藏（驗證是否與 initSystem 有關）

在 `initSystem` 中暫時註解掉 forEach：

```javascript
// if(User && !User.isAdmin) {
//   ['d-nav-report',...].forEach(id => { ... });
// }
```

若空白消失，再細查隱藏邏輯。

### B. 加 console.log 確認執行與資料

在以下位置加入：

- `openReport()` 開頭：`console.log('openReport');`
- `renderReport()` 開頭：`console.log('renderReport', document.getElementById('today-list'));`
- `switchView()` 開頭：`console.log('switchView', v, document.getElementById('view-'+v));`

用手機 Chrome 遠端除錯，切分頁時觀察 Console 輸出與錯誤。

### C. 比對 index-from-751 結構

暫時把 body、main 的 class 改回 751 版本，看空白是否改善，以判斷是否與 layout 有關。

---

## 五、結論

initSystem 只對 nav 按鈕做 `display: none`，理論上不會直接讓 view 空白。  
下一步建議：  
1) 用 A 確認是否與隱藏邏輯有關；  
2) 用 B 確認 JS 有無執行、元素是否存在；  
3) 用 C 判斷是否為版面（body/main）差異導致。
