# 手機版空白頁 — 專案完整檢查

> 建立日期：2025-03-12

---

## 一、部署說明（重要）

### 前端 vs 後端部署

| 項目 | 部署平台 | 修改後需做什麼 |
|------|----------|----------------|
| **pos（前端）** | **Netlify** | 必須重新部署 Netlify，線上網站才會更新 |
| **pos-backend（後端）** | Railway | 後端改動才需重部署 Railway |

### 關鍵：改 index.html 後「一定要」重新部署 Netlify

- 只改本地 `pos/index.html`，若沒有重新 deploy 到 Netlify，**手機開 Netlify 網址時看到的仍是舊版**
- 更新方式（擇一）：
  1. Netlify Dashboard → 專案 → Production deploys → 拖放更新後的 `pos` 資料夾
  2. 若用 Git：push 到 GitHub，Netlify 若已連線會自動部署
  3. Netlify Drop：https://app.netlify.com/drop → 拖放整個 pos 資料夾

### 如何確認是否已更新

- 在 index.html 加一行明顯改動（例如暫時改標題文字），deploy 後用手機重整，看是否有變
- 或檢查 Netlify 部署紀錄的部署時間

## 二、空白分頁：各分頁邏輯檢查

### 未結（view-pending）
- 觸發：`openPending()` → `switchView('pending')` + `loadPending()`
- 依賴：API `/pending`，需要 token（pos_token）
- 可能空白原因：API 失敗、401、或 renderPendingList 未執行
- 預期：至少有標題「未結帳款」，列表區會顯示「無未結帳款」或資料

### 歷史（view-history）
- 觸發：`openHistory()` → `switchView('history')` + `setQuickDate('month')`
- 注意：**不會自動呼叫 doHistorySearch()**，需使用者按「搜尋」才會載入
- 預期：看到日期欄、按鈕、統計區，列表初始為空屬正常

### 進貨（view-restock）
- 觸發：`switchView('restock')` → `setRestockMode(UI.rsMode)`
- 依賴：`DB.inv`（來自 fetchData / getInventory）
- 預期：至少看到「配件進貨」「雜項與薪資」按鈕、搜尋欄；若 DB.inv 空則格子供貨區空

### 設定（view-setting）
- 觸發：`switchView('setting')`
- 全靜態 HTML，無 API
- 預期：一定看得到「系統設定」、同步按鈕、公司配件等區塊
- 若設定也空白：極可能是**版面 / CSS 問題**，不是資料問題

## 三、版面 / CSS 現況（已套用）

- body: `h-[100dvh]`、`min-h-[100dvh]`
- main: `min-h-0`、`pb-16 md:pb-0`
- 手機版 main: `height: calc(100dvh - 4rem)`（@media max-width 767px）
- 各 view-section: `min-h-0`

若仍空白，可再檢查：

1. **100dvh 支援**：舊版 iOS Safari 可能不支援，可加 fallback：`height: 100vh; height: 100dvh;`
2. **主內容被遮住**：檢查 z-index，nav 為 z-50，main 內容是否被覆蓋
3. **view 未正確顯示**：用開發者工具看該 view 的 `display`、`height` 是否為 0

## 四、API 與權限

- 未結、歷史需要管理員（User.isAdmin），非管理員會跳出「權限不足」，不會進入畫面
- 若可進入但空白：可能是 API 失敗（401、CORS、網路錯誤）
- 檢查：手機開 Chrome 遠端除錯，看 Network 中 `/pending`、`/history` 的狀態碼與回應

---

## 五、排查流程建議

1. **確認部署**：改 index.html 後是否有重新 deploy 到 Netlify
2. **確認網址**：手機測試時開的是 Netlify 網址，還是 file:// 或 localhost
3. **區分空白類型**：
   - 完全看不到任何字（連標題都沒有）→ 版面問題
   - 有標題但列表空 → API 或資料問題
4. **手機除錯**：Chrome DevTools 遠端除錯，檢查 view 的 height、Console 錯誤、Network 請求
